# Project Guidelines for Agents

## Scope and Assumptions

- **Assume the main (downloaded) Lean theorem is correct.**
- The goal of this project is **to understand the proof**, not to verify, re-prove, or audit the correctness of the main Lean theorem.
- Focus efforts on analysis, explanation, structure, dependencies, interfaces, and mathematical/architectural comprehension rather than formal verification or checking for proof gaps/axioms unless explicitly asked.
